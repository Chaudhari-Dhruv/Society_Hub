🏢 SocietyHub – Society/Apartment Management System

A web-based Apartment and Society Management System developed using C#, ASP.NET Core MVC, Entity Framework Core, and SQL Server. The application provides a centralized platform for administrators, residents, and security guards to efficiently manage daily society operations.
📌 Project Objective

To simplify residential society management by digitizing maintenance, visitor management, complaints, notices, and event handling through a secure web application.
